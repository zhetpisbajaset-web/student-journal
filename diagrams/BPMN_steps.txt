BPMN swimlanes: Оқытушы | Электрондық журнал
AS-IS (қазіргі): Start -> журнал/Excel ашу -> студентті табу -> бағаны енгізу -> қатысуды белгілеу -> файлды сақтау -> нәтижені сұрағанда іздеу -> орташа баллды қолмен есептеу -> End.
TO-BE (ұсынылатын): Start -> топ/пән таңдау -> студентті таңдау -> баға/қатысу енгізу -> жүйе мәнді тексеру -> [дұрыс?] -> қате болса хабарлама/қайта енгізу; дұрыс болса дерекқорға сақтау -> орташа балл автоматты есептеу -> тізім/есеп көрсету -> End.
